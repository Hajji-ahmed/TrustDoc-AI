{\color{navy}\bfseries\large
An AI-assisted screening tool that returns evidence a reviewer can act on ---
not a verdict.}

\vspace{4pt}
{\footnotesize\color{muted}
Live prototype: \href{https://trust-doc-ai.vercel.app}{trust-doc-ai.vercel.app}

%% ---------------------------------------------------------------- body

\begin{block}{Problem}
Official documents are falsified through edited text, replaced photos, forged
stamps, altered QR codes --- and now through AI generation.

Manual review is slow, repetitive, and misses precisely the subtle cases.
\end{block}

\begin{block}{Target users}
Teams that verify documents at volume: recruitment, finance, compliance and
administration.
\end{block}

\begin{block}{Evidence}
Three tests run against the working prototype:
\begin{itemize}
  \item AI-generated invoice, visually flawless $\rightarrow$ scored low risk.
  \item Invalid tax identifier length $\rightarrow$ missed by the model.
  \item Low score returned with a reject verdict $\rightarrow$ contradictory output.
\end{itemize}
Each finding changed the build. Interviews are under way to rank use cases.
\end{block}

\begin{block}{Solution}
{\footnotesize\color{navy}\bfseries
Upload $\rightarrow$ Normalization $\rightarrow$ Multimodal analysis
$\rightarrow$ Deterministic checks $\rightarrow$ Risk score $\rightarrow$ \mbox{Report}}

A division of labour. The model reads the document and spots visual
manipulation. Code counts digits, verifies checksums and re-adds columns ---
exactly what models fail at. Every flag is drawn and numbered on the document,
so the reviewer sees \emph{where} to look.
\end{block}

\begin{block}{Prototype --- live}
\begin{itemize}
  \item PDF, JPG, PNG. Preview and model input are the same image, so flagged
        regions always align.
  \item Strict JSON schema, re-validated server-side.
  \item Deterministic checks: identifier length, VAT arithmetic, date
        coherence, IBAN mod-97.
  \item Output: risk score, flagged regions, extracted fields, explanation,
        recommended action.
  \item Demo mode without an API key.
\end{itemize}
{\footnotesize\color{muted}
Target architecture, out of 72h scope: OCR tuning, dedicated manipulation
models, metadata forensics, cross-document checks.}
\end{block}

\begin{block}{Validation}
Focus: how documents are verified today, which frauds are hardest to catch,
and what evidence earns a reviewer's trust. A learning log records who was
contacted, what was learned, what was surprising, and what changed as a result.
\end{block}

\begin{block}{Business logic}
\lead{Customer} \ Organizations verifying documents at volume --- lenders,
insurers, recruiters, schools, administrations.\\
\lead{Value} \ Less manual screening, faster triage, traceable evidence.\\
\lead{Model} \ B2B SaaS per seat or per document, plus an integration API.\\
\lead{Market} \ Finance, recruitment, insurance, education, public sector.\\
\lead{Next 30 days} \ Pilot with one organization, add metadata forensics and
cross-document consistency, test pricing.
\end{block}
